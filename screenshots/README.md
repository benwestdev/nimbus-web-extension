# Screenshots

This directory contains screenshots of the extension in action.

## Required Screenshots

To complete the documentation, please add the following screenshots:

1. **extension-popup.png** - Screenshot of the extension popup showing saved templates
2. **salesforce-form-panel.png** - Screenshot of the floating panel on a Salesforce form
3. **save-template.png** - Screenshot showing the save template dialog
4. **load-template.png** - Screenshot showing template selection and load
5. **populated-form.png** - Screenshot of a form after loading a template

## How to Take Screenshots

1. Load the extension in Chrome
2. Navigate to a Salesforce org
3. Use Chrome's built-in screenshot tool (Ctrl+Shift+P > "Capture screenshot") or a third-party tool
4. Save screenshots with the names listed above
5. Place them in this directory

Once screenshots are added, update the main README.md to include them:
